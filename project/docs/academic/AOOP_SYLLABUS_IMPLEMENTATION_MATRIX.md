## Suggested demonstration sequence

1. Construct an invalid `GeoPoint` and show constructor validation.
2. Use the donor account to grant `LOCATION_DISCOVERY`; explain that revocation clears coordinates in the same transaction.
3. Search from an explicitly selected hospital/blood-bank organization; show an opaque result and approximate straight-line distance band.
4. Inspect `DonorProfileRepository.findNearbyOptedIn`: consent, availability, freshness, bounding box, exact radius, nearest-first ordering and result cap all run in the database.
5. Compare with allocation: suggestions are advisory, while confirmation uses authenticated Java services and transactional persistence.

No FHIR compliance or clinical eligibility determination is claimed.

# AOOP Concept → Implemented Code Mapping

Date: 24 November 2026
Status: evidence-based mapping to `project/backend/src/main/java/com/lifelink`, `project/backend/src/test/java/com/lifelink`, `project/frontend/src`, and the recorded runs in [`../quality/TEST_RESULTS.md`](../quality/TEST_RESULTS.md). Historical Phase 2 counts are preserved in dated review records.

The superseded version of this document mapped a planned design: it cited `inventory/domain`, `shared/domain`, `BloodUnitFactory`, `AbstractAllocationStrategy`, `ExactMatchStrategy`, `ExpirySoonestStrategy`, `AllocationFacade`, `Template Method`, generic domain events, an ArchUnit suite, and reflection tests for "no public setters". **None of those classes or tests are present.** This version maps only code that exists. It is not a claim that every OO ideal from `LAB-WORK/PRACTICAL-2` and `PRACTICAL-3` was achieved; deviations are listed at the end.

- [x] SOLID: S, O, L, I, D (with the pragmatic deviations noted below).
- [x] Patterns: Strategy, Specification, Repository, narrow Observer/Outbox.

## Deliberately not claimed (superseded planned items)

- No `BloodUnitFactory`, `DonationUnitFactory`, `AllocationAdvisor`, `AllocationFacade`, `AbstractAllocationStrategy`, `ExactMatchStrategy`, `ExpirySoonestStrategy`, or `SiteProximityStrategy`.
- No `shared` package, no `domain`/`infrastructure` sub-packages, no `OutboxPort`/`AuditPort`/`IdempotencyPort` port interfaces, no `BloodUnitLockPort`/`BloodUnitSearchPort`.
- No typed id value objects, `BloodRequirement`, `ExpiryWindow`, `ScreeningResult`, `RejectionReason`, or `RecipientName` classes.
- No generic domain-event bus with `SKIP LOCKED` polling, no unique `(userId, eventId)` deduplication, no per-aggregate ordering guarantee, and no exported outbox metrics.
- No Template Method hierarchy, no ArchUnit dependency or architecture test, no reflection test asserting "no public setters" or `final` domain classes, and no `InventorySpecification.and/or/not` composition.
- Entities carry JPA annotations and services depend on Spring Data interfaces; the planned framework-free domain layer was not adopted.
- A browser SockJS/STOMP bridge is implemented: it authenticates CONNECT, subscribes to `/user/queue/notifications`, and invalidates React Query caches. The standalone Node smoke remains server-path evidence ([`../evidence/STOMP_SMOKE_RESULT.json`](../evidence/STOMP_SMOKE_RESULT.json)); browser frames are recorded in [`../evidence/BROWSER_STOMP_RESULT.json`](../evidence/BROWSER_STOMP_RESULT.json). The REST inbox remains authoritative, and no client-to-server SEND workflow exists. Playwright E2E results are recorded in [`../evidence/PLAYWRIGHT_RESULTS.json`](../evidence/PLAYWRIGHT_RESULTS.json).

# AOOP Concept → Planned Implementation Mapping

> **Status: mapping to the planned implementation, not verified code.** The initial audit (`../audit/INITIAL_REPOSITORY_AUDIT.md`) recorded no Java sources, no build file, and no tests at baseline. Every path and class below is an intended design target under `project/backend/src/main/java/com/lifelink/...`, consistent with [`../architecture/DOMAIN_MODEL.md`](../architecture/DOMAIN_MODEL.md) and [`../architecture/API_CONTRACTS.md`](../architecture/API_CONTRACTS.md). Test names are planned, not recorded results.

All examples follow the lab findings: no public setters, immutable value objects, defensive/immutable collections, value-based equality on stable ids, and no constructor leaks or overridable lifecycle methods (`LAB-WORK/PRACTICAL-2`, `PRACTICAL-3`).
